# Cricket-Performance-Analytics-Dashboard-SQL-Power-BI
Project Overview

This project analyzes cricket match and player performance data using SQL for data transformation and Power BI for interactive visualization. The objective was to derive actionable insights on player performance, team statistics, and match outcomes.

🗂 Dataset

10K+ ball-by-ball / match-level records

Player statistics (runs, wickets, strike rate, economy)

Team performance metrics

Match results and venue details

⚙️ Key Work Done

Wrote optimized SQL queries (Joins, CTEs, Aggregations, Window Functions) to analyze player and team performance

Calculated advanced KPIs such as Strike Rate, Economy Rate, Batting Average, and Win %

Built interactive Power BI dashboards with dynamic filters, drill-through pages, and DAX measures

Created performance comparison views for players and teams

📊 Key Insights

Identified top-performing batsmen and bowlers

Analyzed impact of venue on match outcomes

Compared team win percentages across formats

Evaluated player consistency and match impact

🎯 Outcome

The project demonstrates strong skills in:

Data cleaning and transformation

Advanced SQL analytics

KPI design

Data storytelling through dashboards
